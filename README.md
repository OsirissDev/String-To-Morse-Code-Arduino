# String-To-Morse-Code-Arduino
Takes a string input and returns another string with morse code. 

Only one function so I didnt make it into a library, copy-paste the code into your script or make a new tab and add it.

Example:
Serial.begin(115200);

Serial.println(toMorse("Hello world"));

Output: .... . .-.. .-.. --- / .-- --- .-. .-.. -..
